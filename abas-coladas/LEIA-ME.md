# Abas coladas (cópia de segurança)

Estas abas vivem coladas na Central (guardadas só no aparelho). Aqui fica uma cópia para não perder.

- **PALCO.html**: Palco com a escolha de voz na aba Fala (vozes da aba VOZ, aparelho, Kokoro, Azure, ElevenLabs).
- **VOZ.html**: Editor de voz (cria vozes a partir de um exemplo).
- **PNG-TUBER.html**: PNG Tuber.

Para usar numa aba: segure a aba na Central › ✎ Trocar o código › Arquivo .html do aparelho.
Cópias feitas a partir do .zip de 28/10/2026; o PALCO já tem a escolha de voz.
